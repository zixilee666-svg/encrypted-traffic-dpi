## 4. 六项核心功能实现情况

| # | 功能 | 实现 |
|---|---|---|
| F1 | 加密流量解析与会话重建（TLS1.3/QUIC/私有协议、乱序重传） | 自写零依赖 PCAP 解析器 + TLS ClientHello 解析 + 五元组会话重组 |
| F2 | 基础特征维度提取 | `etc_core.build_view()` 统一内核，**162 维**（v5）：包长/方向/IAT/PSH/计数器/直方图 |
| F3 | 高级维度提取和生成 | Context Inputs **54 维**、packet-motif、多模态 SEQ+Context 融合 |
| F4 | 智能总结可用维度并**生成规则文件** | 从 RF 森林自动萃取 **384 条规则**（均 5.70 条件，159.4 KB） |
| F5 | 可解释、成体系、逻辑严谨的 DPI 规则引擎 | **四级处置链**：规则直判 → 早期模型 → 全视图模型 → 候选集转人工 |
| F6 | 基于规则高效运行并输出结果 | `dpi_engine/` 独立运行时，`37,339 流/秒`，输出标签+置信度+处置等级+候选集 |
